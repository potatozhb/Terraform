1. install azure cli. https://learn.microsoft.com/en-us/cli/azure/install-azure-cli-windows?view=azure-cli-latest&pivots=winget
2. "az login" to loign the cloud and choose a subscription.
3. "az account show" to verify the account information.
4. install terraform extension that developed by "Anton Kulikov", not offical one
5. Azure provider document: https://registry.terraform.io/providers/hashicorp/azurerm/latest/docs
6. "terraform init" initialize backend to local.
7. Show the plan: "terraform fmt", then "terraform plan"
8. Apply the plan "terraform apply -auto-approve"
9. Check the current state: "terraform state list" "terraform state show 'resource name'"
10. Destroy resource: "terraform plan -destroy"  "terraform apply -destroy"

11. Create key pair:
    "ssh-keygen -t rsa"
12. Use the public key into a VM key by "public_key = file("~/.ssh/key.pub)"
13. After apply the change, try login the VM: "ssh -i ~/.ssh/id_rsa adminuser@168.62.x.x(VM public key)"
    check status: "lsb_release -a"     exit command: "exit"

14. Create Docker steps
    create a new file, for example "customdata.tpl", tpl means temp file
15. Paste the code into the file "customdata.tpl" to install all docker dependency into the machine>
    #!/bin/bash
    sudo apt-get update -y &&
    sudo apt-get install -y \
    apt-transport-https \
    ca-certificates \
    curl \
    gnupg-agent \
    software-properties-common &&
    curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add - &&
    sudo add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" &&
    sudo apt-get update -y &&
    sudo sudo apt-get install docker-ce docker-ce-cli containerd.io -y &&
    sudo usermod -aG docker ubuntu

16. Apply the change, get the new VM public IP, redo step 13, then check the docker version by "docker --version" to make sure it is installed success.

//Remote ssh
17. Install Remote - SSH extension
18. View->Command Palatte->Remote-SSH:Add New SSH Host...
19. Input "ssh admin@admin.com", hit enter button
20. Click the first one "C:\Users\{user name}\.ssh\config, then open the config.

21. Add template file like windows-ssh-script.tpl 
    add-content -path c:/users/joezhao/.ssh/config -value @'

    Host ${hostname}
        HostName ${hostname}
        User ${user}
        IdentityFile ${identityfile}
    '@

    or linux-...
    cat << EOF >> ~/.ssh/config

    Host ${hostname}
        HostName ${hostname}
        User ${user}
        IdentityFile ${identityfile} 
    EOF
22. Replace the resource: terraform apply -replace azurerm_linux_...mtc-vm
23. Run command "ssh-keygen -R 168.62.60.12 -f "$env:USERPROFILE\.ssh\known_hosts" " to delete the cached hosts.

24. If multiple deployment file, define data like this:
    data "azurerm_public_ip" "mtc-public-ip" {
        name                = azurerm_public_ip.mtc-public-ip.name
        resource_group_name = azurerm_resource_group.mtc-rg.name
    }

25. Start terraform console toole by command: "terraform console"

26. sudo apt update
    sudo apt install -y curl wget tar ca-certificates libstdc++6
